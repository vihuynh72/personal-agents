## Theme

"Build a personal agent that does something useful beyond a chat window. Pick one real task, make it work end to end, and show what your agent can do."

## Challenge statement

"Build a shopping agent with an audit trail." The agent should help someone make a purchase or complete a shopping task, use reliable context to make decisions, take a meaningful action, and show the information and steps behind what it did.

Team reading: shopping is a nice-to-have, not mandatory. The audit trail (show the context and steps behind each action) is the part worth keeping whatever we build.

## Submission requirements

- A GitHub repository reviewers can access.
- A short demo video with a shareable link.
- What we built and the tools we used.
- Team names and contact emails.
- Optional: a working website and a project screenshot.

This settles the team debate: a demo video and repo are required, a live link is optional.
